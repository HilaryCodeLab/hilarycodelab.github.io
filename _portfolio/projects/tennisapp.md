## Description: 
This web application is designed for local tennis players who regularly participate in social games. It allows players to record and manage match scores while providing visual statistics to track wins, personal bests, and overall performance. By reviewing their tennis history and progress, players can identify areas for improvement and better understand their performance over time.

## URL:
[tennisbearapp.com](https://tennisbearapp.com/)

## Tech Stack:
* Frontend: ReactJs
* Backend: PHP
* Framework: Laravel
* Database: MariaDB
* Containerization: Docker
* Cloudflare: App's security and traffic management
* Raspberry Pi 5: Web Server
